Vehicle Number Plate Verification System — Full Explanation

Vehicle Number Plate Verification System ایک educational/demo project ہے جس کا مقصد یہ دکھانا ہے کہ vehicle registration number کے ذریعے کسی vehicle کا record کس طرح search اور verify کیا جا سکتا ہے۔

1. Main Purpose

User website پر:

Vehicle Number enter کرتا ہے۔
Chassis Number enter کرتا ہے۔
Captcha enter کرتا ہے۔
Search button پر click کرتا ہے۔

System entered information کو موجودہ demo records کے ساتھ check کرتا ہے۔

2. Vehicle Number

Vehicle number registration/number plate کو represent کرتا ہے، مثلاً:

MLK-678

یہ vehicle کی registration identification کے لیے استعمال ہوتا ہے۔

3. Chassis Number

Chassis number vehicle کا unique identification number ہوتا ہے۔ Demo project میں اسے اضافی verification کے لیے استعمال کیا جا سکتا ہے۔

مثال:

JTD12345678901234

4. Captcha

Captcha یہ check کرنے کے لیے ہوتا ہے کہ search کرنے والا automated bot نہیں ہے۔ User تصویر میں موجود numbers کو input box میں enter کرتا ہے۔

5. Search System

جب user Search پر click کرتا ہے تو JavaScript entered data کو check کرتی ہے۔

اگر record موجود ہو:

Vehicle Found!

اور demo information دکھائی جاتی ہے، مثلاً:

Owner Name
City
Vehicle Model
Registration Status
Chassis Number
